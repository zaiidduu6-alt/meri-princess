GitHub Pages setup
1. Upload ALL files in this folder to the root of your GitHub repo (index.html must be at the top level).
2. Enable Pages: Settings > Pages > Deploy from branch > main / (root).
3. Open index.html in a text editor and replace the placeholder
   https://YOUR-USERNAME.github.io/YOUR-REPO/
   with your real site URL (keep the trailing slash). It appears 3 times
   (og:image, og:url and twitter:image). Commit the change.
   WhatsApp needs this absolute URL to show the preview.jpg preview.
Note: WhatsApp caches link previews. If you shared the link before fixing it, use a new link
or add ?v=2 to the end.
